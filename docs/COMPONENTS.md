# Component reference

Auto-generated by `python -m engine.docgen`. Every component also accepts `heading`, `subheading`, `trigger_keyword`. Items inside lists accept `trigger_keyword` too (the item appears the moment that word is spoken).

**Colours** (`color_theme` / `theme_color`): accent, cyan, blue, green, red, amber, purple, coral, pink, teal, lime, gray

**Best for:** system design, data pipelines, request flows, microservices, networking, CI/CD

## Timeline

**Best for:** history, roadmaps, company story, version releases, biography, project plans

| field | type | default |
|---|---|---|
| `trigger_keyword` | `str` | '' |
| `heading` | `str` | '' |
| `subheading` | `str` | '' |
| `events` | `List[TimelineEvent]` | required |

## TitleCard

Big animated title with optional eyebrow, subtitle and badge. Intros, chapter breaks, outros.

**Best for:** video intro, chapter title, section divider, closing statement

| field | type | default |
|---|---|---|
| `trigger_keyword` | `str` | '' |
| `heading` | `str` | '' |
| `subheading` | `str` | '' |
| `eyebrow` | `str` | '' |
| `title` | `str` | required |
| `subtitle` | `str` | '' |
| `badge` | `str` | '' |
| `theme_color` | `Literal['accent', 'cyan', 'blue', 'green', 'red', 'amber', 'purple', 'coral', 'pink', 'teal', 'lime', 'gray']` | 'accent' |
| `align` | `Literal['center', 'left']` | 'center' |

```json
{
  "component_type": "TitleCard",
  "eyebrow": "DEEP DIVE",
  "title": "How Kafka Actually Works",
  "subtitle": "Logs, partitions and consumer groups in 60 seconds",
  "badge": "2025"
}
```
